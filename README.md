# Trivia Quest

A responsive, browser-based trivia game. Pick a category or play a mixed round, answer questions before the timer runs out, and see your score at the end.

## Play

Open `index.html` in a modern web browser. No installation, server, or build step is required.

## How it works

- Choose from Science, History, Pop Culture, Geography, Nature, or Surprise Me.
- Answer five multiple-choice questions per round.
- Each question has a 15-second timer.
- Earn points for correct answers, with extra points for answering quickly.
- Review your results and start another round whenever you like.

## Project files

- `index.html` — page structure and game screens.
- `styles.css` — responsive layout and visual styles.
- `game.js` — trivia questions, timer, scoring, and game flow.

The game uses plain HTML, CSS, and JavaScript. Google Fonts are loaded from the web; system fallback fonts are used if they are unavailable.
